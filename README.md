# Itagra

Sitio institucional de Itagra, inmobiliaria de parcelas de agrado. Su primer proyecto es Pircas de Lliu Lliu, ubicado en Limache, Región de Valparaíso.

## Desarrollo local

Requiere Node.js 22 o superior.

```bash
npm install
npm run dev
```

La web estará disponible en `http://localhost:3000`.

## Publicación en Vercel

1. Importa este repositorio desde el panel de Vercel.
2. Mantén el preset **Next.js** detectado automáticamente.
3. No agregues variables de entorno: esta versión no las necesita.
4. Presiona **Deploy**.

Cada cambio enviado a la rama `main` generará una nueva publicación automática.
